## OpenCV-Draft

This repository contains some basic image processing and image manipulation techniques using OpenCV and NumPy in Python. It also includes a modular GUI-based photo editor built with PySide6.

Features include:
- Grayscale and blur filtering
- Brightness adjustment
- Interactive HSV color masking.
- Background removal with grayscale background effect
- Real-time image processing and visualization

Many examples and implementations in this repository are based on the official OpenCV Python tutorials.
